# syed1789.github.io

Personal portfolio site for Syed Nurul Hasan, Ph.D. — Computational Immunologist.

Live at: https://syed1789.github.io/

## Editing

Single self-contained file, no build step:

- `index.html` — everything (styles, content, scripts) in one file.

Edit it directly, then:

```bash
git add index.html
git commit -m "Update portfolio"
git push
```

Changes go live at the URL above within a minute or two of pushing.
